# Contributing

**This is a personal project. External contributions are not accepted.**

## Why This Repository Doesn't Accept Pull Requests

This repository is a personal bookmark and RSS aggregator designed for single-user use. It does not follow the structure or governance model of open-source projects.

External contributions are blocked to:
- **Protect privacy**: Bookmarks reflect personal interests
- **Ensure security**: Minimize external code execution in CI/CD pipelines
- **Maintain focus**: Keep the project aligned with personal use cases only

## What You CAN Do

You are welcome to:
- **Fork this repository** and modify it for your own use (MIT licensed)
- **Cite this code** in your own projects
- **Build inspired projects** using similar architecture
- **Report security issues** via GitHub DM (see [SECURITY.md](SECURITY.md))

## What You CAN'T Do

- Submit pull requests (disabled)
- Request features via issues
- Report bugs (unless you offer to fix them, but no external PRs accepted)
