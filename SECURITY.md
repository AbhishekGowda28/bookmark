# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it responsibly.

**Do NOT:**
- Open a public GitHub issue
- Post in discussions
- Create a pull request with the fix

**Instead:**
- Contact me via GitHub: [@AbhishekGowda28](https://github.com/AbhishekGowda28)
- Send a private message with:
  - Description of the vulnerability
  - Steps to reproduce (if applicable)
  - Potential impact
  - Suggested fix (if you have one)

**Response Time:** I will acknowledge your report within 7 days.

---

## Security Features Enabled

This repository has the following protections:

- ✅ **Secret scanning**: Blocks commits containing API keys, tokens, or credentials
- ✅ **Push protection**: Prevents accidental secret leaks
- ✅ **Branch protection**: All changes to `main` require approval
- ✅ **Workflow restrictions**: External actors cannot trigger CI/CD pipelines
- ✅ **Dependabot**: Automatic security updates for dependencies
- ✅ **No external PRs**: Only verified changes merge to main
